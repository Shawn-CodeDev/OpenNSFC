# 国家自然科学基金 2026 年申请书要求（官方口径）

> **本文档是本流水线全部结构判断的依据来源。**
> 政策逐年调整，**正式提交前必须以当年 ISIS 系统下载的官方提纲与《项目指南》为准**。

---

## 一、2026 年"瘦身提质"改版（核心变化）

**来源**：国家自然科学基金委员会 2025-12-30 发布，新华社报道，基金委官网同步刊发。

### 原文要点（逐字引用）

> 自然科学基金委积极响应学术界的关切和诉求，在2026年启动申请书"瘦身提质"行动。我们将对申请量最大、覆盖面最广的两类项目——面上项目和青年科学基金项目（C类）的申请书提纲进行优化调整。

> **调整后的申请书正文包括立项依据、研究内容及研究基础三部分。**

> **⚠️ 注意这处官方表述与实际提纲的差异**：基金委 2025-12-30 的新闻稿说"三部分"，
> 但随后发布的**正式撰写提纲是四部分**——在上述三部分之外还有
> **（四）其他需要说明的情况**（共 6 项，第 5 项为生成式 AI 使用披露）。
> 新闻稿的"三部分"是在强调**主要变化集中于这三部分**，并非取消了（四）。
> **以提纲为准**：本包的校验器、模板与 `templates/*-提纲.txt` 都按**四部分**处理。
> 这也解释了为什么不能只看新闻稿写申请书。

> 在立项依据部分，只需要说清楚"为什么要开展此项研究，研究的价值何在"；**研究内容部分不再预设提纲限制，申请人可以根据自己的研究思路和研究工作的自身逻辑自主撰写**；研究基础部分主要展示前期的工作积累。

> 两类项目的申请书正文**篇幅原则上不超过30页**，鼓励简洁表达。

> 申请人**不必再为"研究方案""技术路线""研究方法"等名词所困扰，也无需对"研究目标"和"拟解决的关键科学问题"有什么本质区别而绞尽脑汁**。

> **用简明扼要的语言撰写申请书，是申请人学术思维与表达能力的体现**。广大申请人要**摒弃申请书撰写的各种"套路"和"话术"**，纠正"篇幅写长一点更容易获得资助"的错误想法，让申请书内容**回归科学研究的本质，充分展示自己的创新思路和学术观点**。

### 对写作的具体约束

| 官方要求 | 落到写作上的约束 |
|---|---|
| 正文**四部分**（新闻稿称"三部分"，见上文注） | 不再有"研究方案/技术路线/研究方法/可行性分析/特色创新点"等独立栏目；（四）含 6 项，第 5 项为 AI 使用披露 |
| 研究内容自主撰写 | **不得**使用"研究目标/研究内容/关键科学问题"三段式小标题 |
| 不超过 30 页（含图表） | 必须做页数预算；图表的权重显著上升 |
| 摒弃套路与话术 | 逐句做"替换检验"；可套用于任何项目的句子必须删除 |
| 回归科学本质 | 科学问题必须是 science 而非 technology |

## 二、科学问题属性（两类制）

**来源**：2024 年起国自然改革举措；2026 年青基填报说明确认延续。

### 官方定义

| 属性 | 定义 |
|---|---|
| **自由探索类基础研究** | 选题源于科研人员**好奇心或创新性学术灵感**，且**不以满足现阶段应用需求为目的**的原创性、前沿性基础研究 |
| **目标导向类基础研究** | 以**经济社会发展需要或国家需求**为牵引的基础研究 |

### 来源与适用范围

- 自 2019 年起，面青地项目曾分为**四类**科学问题属性分类评审："鼓励探索，突出原创""聚焦前沿，独辟蹊径""需求牵引，突破瓶颈""共性导向，交叉融通"
- **2024 年起简化为两类**：自由探索类（由原前两类合并）、目标导向类（由原后两类合并）
- **适用范围**：重点项目、面上项目、青年科学基金项目。**不包含地区项目**

### 属性对撰写的影响

| | 自由探索类 | 目标导向类 |
|---|---|---|
| 首要评判标准 | 原创性、前沿性 | 国家需求、社会需要 |
| 预实验要求 | **更高**（明确要求） | 需论证需求真实性 |
| 应用前景论证 | 不需要 | 必须，且需说清需求—科学问题通路 |
| 不被资助的情形 | 套路化、硬蹭热点的研究 | 纯理论、离应用转化有距离的项目 |

## 三、生成式 AI 使用声明

**来源**：2026 年青年科学基金项目（C类）填报说明。

- 如使用 AI 工具辅助撰写，**需说明具体位置和内容**
- 配套要求：内容需符合年度项目指南，不得包含涉密或敏感信息

**操作建议**：
- 让 AI 承担**结构梳理、文献整理、表述打磨与自检**
- **研究思路、科学假说、创新观点由申请人本人提出并定稿**
- 官方明确要求研究内容部分按申请人**自己的研究思路**自主撰写

## 四、正文结构（合并后的形态）

```markdown
# <项目名称>

## 一、立项依据
回答：为什么要开展此项研究，研究的价值何在
内容：领域现状与能力边界 → 瓶颈 → 结构性缺陷 → 科学问题与假说 → 价值

## 二、研究内容
回答：要做什么、怎么做、怎么验证
组织：按研究工作的自身逻辑（推荐"假说验证链"），无固定提纲
内容：研究内容分项 + 核心洞察 + 方法 + 技术路线图 + 验证方案 + 创新点 + 年计划 + 预期成果

## 三、研究基础
回答：前期的工作积累
内容：前期积累与预研发现（主体）+ 条件与资源 + 团队 + 在研项目与前期基金完成情况

## 参考文献
格式：GB/T 7714-2015（除非申报书另有规定）
```

### 页数预算建议

2026 版正文是**四部分**（参考文献含在（一）内），上限 30 页含图表。
建议按下表分配——依据是两份已获批本的**真实篇幅配比**
（见 `docs/获批本解剖.md` 第 1、11 节），而非拍脑袋：

| 部分 | 青年C类 | 面上项目 | 说明 |
|---|---|---|---|
| （一）立项依据 | 8–10 页 | 11–16 页 | 面上要把现状写厚（实测占 31%） |
| （二）研究内容 | 12–14 页 | 9–11 页 | 含特色与创新点、年度计划、技术路线图、验证方案 |
| （三）研究基础 | 3–5 页 | 4–6 页 | 面上证据更多（专利/软著/实机测试） |
| （四）其他需要说明的情况 | 1–2 页 | 1–2 页 | 含生成式 AI 使用披露 |
| **合计** | **≤30 页** | **≤30 页** | 含图表 |

**两条来自实测的校准**：

1. **研究方案（（二）的主体）必须占正文最大份额**：青年本实测 41%、面上本 32.5%，
   且两份获批本**超字数的地方正好都在研究方案**——说明这是评审最想读的部分。
   若取舍，砍研究意义、保研究方案。
2. **面上项目的现状综述要接近青年的两倍**（31% vs 15%）。面上评审要求申请人
   对整个方向的格局有判断力，把现状压到 15% 会被认为"视野不够"。

> **注意**：不要在正文里保留"第一部分/第二部分"这类旧说法。2024 版及以前把
> 立项依据与研究内容合并为"（一）"，2026 版拆为四部分，旧称谓会让评审看出
> 用的是往年模板。

## 五、参考文献格式：GB/T 7714-2015

### 会议论文

```
[序号] 作者. 题名[C]//论文集名. 出版地: 出版者, 出版年: 起止页码.
```

示例：
```
[1] Vaswani A, Shazeer N, Parmar N, et al. Attention is all you need[C]//Advances in Neural Information Processing Systems. Long Beach: Curran Associates, 2017: 5998-6008.
```

### 期刊论文

```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```

示例：
```
[2] 作者1, 作者2, 作者3, 等. 论文题名[J]. 计算机学报, 2023, 46(5): 1000-1015.
```

### 电子资源/预印本

```
[序号] 作者. 题名[EB/OL]. (发布年-月-日)[引用日期]. 获取路径.
```

### 常见错误（务必避免）

| 错误 | 说明 |
|---|---|
| 会议条目缺页码 | GB/T 7714 要求给出起止页码 |
| 期刊条目缺卷或页 | 必须含 卷(期): 页 |
| 会议条目缺 `//` | 会议论文用 `[C]//` 连接论文集 |
| 中文文献用英文标点 | 按语种各自规范 |
| 条目信息凭记忆填写 | **不得**；无法核实应标注"待确认"并移出正式列表 |

> 注：部分申报书对格式另有规定（如要求标注影响因子/分区）。以当年填报说明为准。

## 六、研究属性选择理由的填写

系统填报时需填写研究属性选择理由。**本流水线不代写**，只做一致性检查：

- [ ] 理由与所选属性一致
- [ ] 自由探索类：理由应体现好奇心/学术灵感驱动、不以现阶段应用需求为目的
- [ ] 目标导向类：理由应点明具体的国家需求或经济社会发展需要，并说明其来源
