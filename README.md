# OpenNFSC

**国家自然科学基金申请书撰写技能包** · *powered by gary*

> 把「一个研究方向」变成「一份可提交的申请书正文与 PDF」——全流程自动化，含官方模板逐字合规校验与引用双向校验。

---

## 这是什么

一套交给 AI agent 就能直接干活的工具包，覆盖国自然申请书撰写的全链条：

```
环境配置 → 文献检索 → 现状梳理 → 科学问题凝练 → 研究方案设计
        → 正文撰写 → 官方模板对齐 → LaTeX 编译 → 自动校验 → PDF 成稿
```

**产出物**：`申请书正文.pdf` + `.tex` + `.md` + 技术路线图，且通过：

- **官方模板逐字合规校验**（对照基金委《报告正文（2026 版）· 青年科学基金项目（C 类）》）
- **引用双向一致校验**（正文引用 ↔ 参考文献列表，兼容全角方括号）

---

## 三步上手

### 1. 环境配置

```bash
node bin/setup.mjs
```

自动完成：Node.js 版本检查 → **TeX Live 检测/安装**（自动挑选可用 CTAN 镜像）→ 中文字体校验 → 文献数据源可达性探测。

只想知道现状不安装：

```bash
node bin/doctor.mjs --check
```

### 2. 自检

```bash
node bin/doctor.mjs
```

逐项检查技能包是否可用。有 `fail` 项时按提示修复。

### 3. 开始写

把本目录交给 agent，说：

```
读 OpenNFSC/AGENTS.md，按流程帮我写国自然青年基金申请书。
研究方向：<你的方向>
申报级别：青年科学基金项目（C类）
执行期限：2027-01 至 2029-12
```

或直接用 Claude Code（会自动识别 `SKILL.md`）。

## 核心能力

### 多源文献检索（含自动故障切换）

```bash
node bin/cli.mjs search --fallback --query "检索式" --out runs/<项目>/work/library.json
```

`--fallback` 会按优先级依次尝试 **7 个数据源**并自动择优。这不是过度设计——实测**源可用性会分钟级反转**：

| 源 | 实测状态 |
|---|---|
| arXiv 网页 / PDF | ✅ 稳定（268ms / 1.8s） |
| OpenReview 官方 BibTeX | ✅ **计算机学科首选**，权威元数据 |
| Crossref | ⚠️ 间歇（成功时 1–10s） |
| arXiv API | ⚠️ https 超时、http 可用 |
| OpenAlex / Semantic Scholar | ⚠️ 持续 429，需 API key |
| DBLP | ❌ 被反爬拦截（HTTP 200 但返回验证页） |
| EuropePMC | ✅ 兜底（学科偏生物医学） |

工具会自动**过滤非文献记录**（Crossref 的同行评审记录、决定信、空标题），并按有效条数**择优取源**。

### 权威元数据核验

```bash
# 会议官方 BibTeX（ICLR/CVPR 等）
node bin/cli.mjs search --source openreview --query "论文标题" --out runs/<项目>/work/library.json

# 按 arXiv ID 走网页路径（含 PDF 下载与完整性校验）
node bin/cli.mjs arxiv-fetch --ids 2303.01469 --out runs/<项目>/work/library.json --pdfDir runs/<项目>/work/pdfs
```

### 引用双向校验

```bash
node bin/cli.mjs validate --manuscript runs/<项目>/deliverables/申请书正文.md \
  --lib runs/<项目>/work/library.json --min-citations 15 --strict
```

`退出码 0 = 通过，2 = 阻断`。检出：正文引用缺失、编号跳号、挂空文献、格式问题、重复 DOI、无引用文档。**兼容中文写作常用的全角方括号 ［1］。**

### 官方模板合规校验

```bash
node bin/check-template.mjs runs/<项目>/deliverables/申请书正文.md
```

逐字比对 18 项提纲标题与括号文字（官方明令"请勿删除或改动"），并检查四部分顺序与 30 页限制。

### 出稿

**两套模板**。2026 年基金委对**面上项目**与**青年科学基金项目（C 类）分别发布**了填报说明、
撰写提纲与正文模板，本包据此提供两套，用 `--track` 选择：

```bash
node bin/md2tex.mjs runs/<项目>/deliverables/申请书正文.md --track youth     # 青年C类
node bin/md2tex.mjs runs/<项目>/deliverables/申请书正文.md --track general   # 面上项目
node bin/compile-tex.ps1
```

| | 青年C类 | 面上项目 |
|---|---|---|
| 正文差异 | 基准 | （三）3 与（四）2/3/4 含**"主要参与者"** |
| 资助期限 | 3 年 | **4 年** |
| 经费 | 包干制，无需编预算 | **须编制预算表** |
| 合作研究单位 | 无明文上限 | **不超过 2 个** |
| 个人简历 | 仅申请人 | 申请人 + **主要参与者** |

两套的 LaTeX 排版完全相同（A4 / 宋体小四 / 1.5 倍行距 / 首行缩进 2 字符 / 页脚页码），
差异只在封面、页眉与正文外约束提示。**提纲原文的唯一真源是 `bin/track-params.mjs`**，
两套模板与校验器都从它取参数，不会出现"模板和校验器各写一份"的漂移。

### PDF 内容自检：专治「编译假成功」

有一类故障，整条编译链路对它**完全静默**——`xelatex` 退出码 0、日志无错误、PDF 也照常生成，**但图根本没进去**（图片路径写错、`\IfFileExists` 走了占位分支等）。

`compile-tex.ps1` 内置三重硬判据 + PDF 内容流解析来堵住它：

```bash
node bin/pdf-probe.mjs runs/<项目>/deliverables/申请书正文.pdf --expect-figure
```

输出如：`绘图算子 9741 / 文本绘制 2483 / 嵌入字体 14`。详细原理见 `bin/USAGE.md` 第 6 节。

### 一致性校验：专治"编译能过但评审一眼看得出"

有三类缺陷**不会**被编译、模板校验或引用校验拦住：

```bash
node bin/check-consistency.mjs runs/<项目>/deliverables/申请书正文.md --strict
```

| 缺陷 | 实测案例（来自一份**已获批**申请书） |
|---|---|
| 术语混用 | 「半监督」18 处 vs 「弱监督」2 处 |
| 图号冲突 | 正文引「图3」，图注写「图 1」，且「图1」重复 |
| 同音错字 | 「事件分辨率可达**微妙**级」（应为微秒） |

这三类问题**人眼通读的漏检率极高**——两处用词相隔数千字、图号要同时记住两个集合、
"微妙"本身是合法词。必须脚本化检查。详细说明见 `bin/USAGE.md` 第 7 节。

### 写作时对照：`docs/获批本解剖.md`

对一份**已获批**青年基金申请书的逐项实测剖析，含：

- **升维链模板**：「本质上，X 问题可理解为 Y 问题」+ 三句平行定性句
- **研究现状四拍**：分类穷举 → 逐类优缺点 → 收口缺口 → 申请人转机
- **枢纽句写法**：用"申请人前期的研究发现"替掉缺口句的引用（实测：所有 gap 句一句不引）
- **篇幅配比实测**：研究方案独占 41%，研究意义仅 11%
- **引用纪律**：陈述他人必引、gap 句不引
- **10 张图的分布规律**：意义处现象图 / 方案处每条内容一张 / 可行性处预研结果图

### 技术路线图：推荐用纯 TikZ

```bash
cp pipeline/templates/technical-roadmap.tikz runs/<项目>/deliverables/图1-技术路线图.tikz
```

正文里正常写 `![图1 技术路线图](图1-技术路线图.png)` 即可——编译器发现同名 `.tikz` 会**自动优先嵌入**。

好处：矢量输出（打印不失真）、**不需要 drawio/Visio**、单一 `.tex` 源文件即可复现整份稿件，agent 能纯文本生成与修改。

**实测样例**：`examples/test-run/` 是一次完整跑通的原始产物（18 条核验文献、22,680 字正文、26 页 PDF），可当作产出形状的参照物。

## 官方模板的硬性约束（**最容易踩的坑**）

| 约束 | 说明 |
|---|---|
| **正文四部分** | （一）立项依据 /（二）研究内容 /（三）研究基础 /（四）其他需要说明的情况 |
| **不得删改提纲标题** | 包括括号内的说明文字，以及结尾的 `；` 与 `。` |
| **（二）必须含** | 特色与创新点（1.1 研究特色 / 1.2 本项目的创新之处）、年度研究计划 |
| **（四）共 6 项** | 第 5 项为**生成式人工智能使用披露**，独立必填 |
| **（三）2 必含** | "尚缺少的实验条件和拟解决的途径" |
| **（三）4 附附件** | 须另附 500 字总结摘要 + 成果详细目录 |
| **篇幅 ≤ 30 页** | 含图表 |
| **不涉及可填"无"** | 官方模板明示 |

## 这个包不做什么

1. **不能替你产出科学洞察。** 它保证结构合规、论证链完整、引用可溯源、格式正确；**不能**把一个平庸的科学问题变好。
2. **不代写研究基础与预研数据。** 这是自由探索类项目竞争力的核心，也是官方评审明确考察的内容。包会搭好完整结构并留出可填槽位，具体内容必须由申请人提供。
3. **不替你决定研究属性。** 自由探索类 / 目标导向类的选择会改变整份申请书的论证策略，必须由申请人确认。
4. **不保证 AI 披露的合规性。** 包会起草一份基于实际使用情况的披露文本，但**请务必逐条核对**——披露不实属科研诚信问题。

## 环境要求

| 项 | 要求 | 缺失时 |
|---|---|---|
| **Node.js** | ≥ 18（需内置 fetch） | **必需**，无法降级 |
| **TeX Live** | 含 ctex / xeCJK | `setup.mjs` 可自动安装；缺失时仍可出 Markdown / HTML，无 PDF |
| **中文字体** | 宋体 / 黑体 | 自动回退 Fandol |
| **网络** | 检索阶段需要 | 可降级为导入已有文献，或纯人工模式 |
| **PowerShell** | 编译脚本需要（Windows） | macOS / Linux 可手动跑 `xelatex` 两遍 |

## 常见问题

**Q：TeX Live 装不上怎么办？**
`setup.mjs` 会依次探测 5 个 CTAN 镜像。若全部不可达，可稍后重试或手动安装。**前 8 个阶段完全不依赖 TeX**——检索、写作、校验、Markdown 出稿都能跑；只有最后的 PDF 生成需要它。

**Q：检索源全部不可用怎么办？**
三条降级路径：① 稍后重试；② 由你提供 RIS/BibTeX 后 `cli.mjs import`；③ 纯人工模式。**注意**：导入的文献库若缺 DOI/页码，将无法生成合规的 GB/T 7714 条目，进而无法通过引用校验——此时应检查 `stats` 输出中的 `withDoi/total`。

**Q：能写面上项目吗？**
可以。流程与青年基金一致，差异在于（三）4 与部分论述深度。若你从 ISIS 下载了面上项目的提纲，用 `check-template.mjs` 对正文校验即可（如需调整校验基准，见 `templates/报告正文-青年C类-2026-提纲.txt`）。

**Q：正式提交前还需要做什么？**
务必以 ISIS 系统下载的**当年官方模板**为准，用 `check-template.mjs` 再校验一次。本包内置的模板来自公开渠道，与基金委 2025-12-30 公开表述一致，但年度模板可能微调。
